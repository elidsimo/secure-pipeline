# SecurePipeline

Plateforme DevSecOps complète — de la conception sécurisée au runtime protégé.

## Stack
- Node.js + Express

## Démarrage local

\`\`\`bash
npm install
npm run dev
\`\`\`

Le serveur démarre sur http://localhost:3000

## Structure du projet
- `src/` — code applicatif
- `docs/threat-model/` — modélisation de menaces
- `.github/workflows/` — pipelines CI/CD sécurisés
